# FoundryNet

**Verified intelligence and trust infrastructure for the agent economy.**

FoundryNet builds the layers AI agents need to work in the real world: connect to any machine, establish and check trust across platforms, and keep a verifiable record of what was done. Signed isn't the same as verified, and we do the verifying.

### The products
- **[Forge](https://forge.foundrynet.io)** ([forge-mcp](https://github.com/FoundryNet/forge-mcp)): industrial machine-intelligence kernel. Cross-OEM telemetry normalization across **18 manufacturer families** and **14 protocols**, plain-English automation, predictive maintenance, and tamper-evident work records. **30 MCP tools**, one universal data layer.
- **[Assay](https://assay.foundrynet.io)**: cross-platform agent identity and trust. Register an agent, attest its work, and let anyone verify it on any platform. Pay per call, first 100 calls free.
- **[MINT](https://github.com/FoundryNet/mint-mcp)** ([mint-mcp](https://github.com/FoundryNet/mint-mcp)): the work-attestation and settlement layer. Register actors, record completed work, and derive a verifiable standing from that settled record.
- **Data intelligence network**: MCP servers for financial, cyber, regulatory, patent, weather, and more intelligence, behind one API key.
