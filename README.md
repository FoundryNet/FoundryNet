# FoundryNet

**Verified intelligence infrastructure for the agent economy.**

FoundryNet runs **21 MCP data servers** — financial, cyber, regulatory, patent, weather, and more — behind one API key, alongside an industrial machine kernel (**Forge**) and a universal work-attestation protocol (**MINT**). Every response is verified: each result carries a tamper-proof provenance record, so an agent can prove the work it did and verify what another agent claims. Signed isn't the same as verified — we do the verifying.

### Start here
- **[forge-mcp](https://github.com/FoundryNet/forge-mcp)** — industrial machine-intelligence kernel: cross-OEM telemetry normalization, plain-English automation, and predictive maintenance.
- **[mint-mcp](https://github.com/FoundryNet/mint-mcp)** — MINT Protocol: register an agent identity, attest work, verify trust, and discover trusted actors.
- **[mint-attest](https://github.com/FoundryNet/mint-attest)** — Python SDK: attest any agent's work with a single `@attest` decorator.
